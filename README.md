# launcher-data

Contenu public lu par le launcher **Le Groupe SMP** : liste des mods,
actualités, config serveur, wiki, et définitions de détection de triche.

Ce repo doit rester **public** (le launcher le lit via
`raw.githubusercontent.com`, sans authentification).

Pour éditer :
- Directement sur GitHub (bouton crayon sur un fichier → modifier → commit).
- Ou en local : `git pull`, édite, `git commit`, `git push`.

Les joueurs voient les changements au prochain lancement du launcher (ou en
cliquant "Actualiser"/"Vérifier les mises à jour" selon l'onglet) — pas
besoin de republier le launcher lui-même.

Voir `SETUP.md` dans le repo du launcher pour le détail de chaque fichier.
